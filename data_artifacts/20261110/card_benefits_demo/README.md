# 카드 혜택 시연 데이터

사용자 요청에 따라 원본 조사 CSV에서 할인율을 추출하고 현행 DB에 맞게 단순화한 데이터입니다. 실제 카드 혜택이나 현재 발급 가능 여부를 검증한 데이터가 아닙니다. 원본의 db_importable=false는 변경하지 않았습니다.

- 실행용 CSV: backend/src/main/resources/data/card_product.csv, discount_rule.csv. 적용 카드 이름에는 [시연용]을 붙였습니다. 기존 card_id는 유지합니다.
- demo_rule_extraction.csv: 50개 원본 각각의 적용 여부, 선택 비율, 생략·근사 조건과 원문입니다.
- before_*.csv: 이번 시연 변환 직전 실행용 CSV의 백업입니다.
- 월/일 통합 한도, 사용 횟수, 시간대, 상품군, 결제 채널 제한은 제외합니다. 월 한도를 1회 한도로 옮기지 않습니다.
- 원문에 명시된 최소 결제액과 건별 최대 혜택은 유지합니다. 불명확한 전월실적 조건은 true로 기록하며 기존 계산기는 충족으로 간주합니다. 행사 중복은 시연용으로 true를 가정합니다.
- 캐시백 일부는 즉시 할인으로 단순화합니다. 적립은 POINT로 유지하므로 결제액에서 차감하지 않습니다.
- 1,500원당 200원은 13.3% 근사이며 실제 계단식 계산과 다릅니다. 5,000원 이상 200원은 4% + 최대 200원 + 최소 5,000원으로 표현합니다.
- 할인율이 없는 상품, 최소 금액 없는 정액 혜택, 발급사/상품명이 미확정인 상품은 보류합니다. 과거 상품을 포함하므로 현재 사용 가능성을 보장하지 않습니다.
- source와 checked_at은 원본 출처와 원본 확인일입니다. 이번 작업에서 재검증하지 않았습니다.
- 이 CSV는 백엔드 시작 시 로드되는 시연용 seed입니다. 프런트엔드 VITE_USE_FIXTURES 설정과 무관하게 백엔드 API의 계산에 적용됩니다. 운영 데이터로 사용하지 마세요.

## 간단한 캡처 예시

CU 상품 정가 2,000원, 행사 없음 기준: 카드 미등록 시 2,000원 → [시연용] CU Npay 카드 등록 시 1,700원 → [시연용] CU KB국민카드로 교체 시 1,400원입니다. 두 카드를 함께 등록하면 합산하지 않고 가장 큰 할인 하나만 적용합니다. 포인트 카드는 결제액을 낮추지 않습니다. 실제 표시 가격은 선택 상품의 정가와 행사에 따라 달라집니다.
