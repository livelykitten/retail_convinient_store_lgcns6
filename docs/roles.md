# 역할 분담

요구사항명세서의 FR · API를 백엔드 4명에게 나누고, 스프린트별 할 일을 정해요. 2026-11-09 「백엔드 역할 분담」 문서(초안)를 옮겼어요. **담당이 바뀌면 이 문서를 먼저 고쳐요.** FR 번호와 API 경로는 요구사항명세서와 같아요.

- 상태: 초안. 이름 배정과 백엔드 리드는 팀장(류지범)이 확정하기 전이에요.
- 함께 볼 문서: 요구사항명세서(FR · 계산 규칙 · API), 수행계획서, 애자일 운영계획

## 협업 약속

- **인터페이스는 제공하는 쪽이 먼저 고정값을 돌려주는 임시 구현을 올려요.** 그래야 함석원이 quotes 조립을 기다리지 않고 시작해요.
- **인터페이스(입력 · 출력)를 바꾸면 쓰는 사람에게도 알려요.** [스펙 변경](CONTRIBUTING.md#스펙-변경) 순서대로 [design.md](design.md)를 먼저 고쳐요.
- **다른 사람 모듈의 리포지토리를 직접 부르지 않아요.** 그 모듈의 Service 메서드를 불러요.
- **리뷰 짝 (안)**: 이서현 ↔ 노건우, 함석원 ↔ 한예림. 이서현은 리드로서 quotes PR과 스키마 변경도 봐요.
- **막히면 "함께 보는 사람"에게 먼저 물어봐요.** 명세를 바꿔야 하면 PM2(민경완)에게 먼저 말해요.

자세한 협업 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)에 있어요.
